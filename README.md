## 📖 About

Slime Chunk Finder highlights slime-spawning chunks in the world overlay using the world seed, making it trivial to locate the perfect slime farm location.

---

## ✨ Features
<a name="features"></a>

- **Chunk Overlay** — green tint on all slime chunks in render distance.
- **Seed Input** — manual seed entry or auto-detect via Seed Cracker.
- **Y-Level Check** — confirms valid slime spawn heights per chunk.
- **Nearest Cluster** — finds the closest cluster of adjacent slime chunks.
- **Toggle Key** — quick on/off without opening settings.
- **Multiplayer Safe** — client-side rendering only.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
